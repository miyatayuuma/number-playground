# CORE BREAK

数そのものが、つかめる塊になる算数バトルです。手元で合体・分離させて敵へ撃ちます。ゲーム中の説明文、数字選択、正誤回答、発射ボタンはありません。

## プレイ

入口はスパーク・リンク・ギア・コアの4択です。固定ステージの選択はなく、クリア演出のあと同じルールの次の問題が始まります。プレイ中はルール名と5段階の難易度を表示します。

- **スパーク**：中央の輪や外周をつかんで塊を運び、内側のまとまりや1粒を引き出します。重ねると合体し、敵の穴へ運ぶと発射します。
- **リンク**：塊の下のつまみを左右に引いて列数を変更します。敵の枠に合う幅に整えて撃つと一列が残り、余りは別の塊になります。残った塊も使い切ってクリアします。
- **ギア**：共通のつまみで二つの塊の列数を同時に変えます。両方に余りがなくなる幅（2以上）はすべて正解。同じ個数の行を、二つの塊から連射します。
- **コア**：長方形に整える合成数、円形のまま使う素数、ブロックを空間的に組み込む正方形を扱います。正方形は全体を合体してから列幅を合わせる解法も使えます。

生成する構成はスパーク966種類、リンク170種類、ギア207種類、コア343種類。直近10問の重複を避けながら継続出題します。初回は難易度1から始まり、再出題なしで3問クリアすると一段階上昇、クリアせずに2回再出題すると一段階下降します。試行、合わない弾、考える時間では難易度を下げません。時間制限や誤操作によるゲームオーバーはありません。

一時停止メニューでルール変更・再出題・音を操作できます。ルールごとの難易度と直近の問題、音設定を保存します。保存が無効でも遊べます。旧版からは音設定だけを引き継ぎ、旧ステージのクリア記録は新しい難易度に換算しません。

端末の「動きを減らす」設定に対応しています。キーボード向け操作はフォーカス時だけ表示されます。既存の4モードは `classic.html` に残しています。

## 数の形

1は1粒、2はペア、3は三角形、4は四角形。合成数は同じ図形が集まる再帰的な形を持ちます。4を優先して因数を取り出し、その逆順で外側から配置するため、8は四角形2つ、9は三角形3つ、12は四角形3つになります。10は放射状に向けた2個組を正五角形に置き、ペア内部よりペア同士の間隔を広く取ります。

[Data PointedのAnimated Factorization Diagrams](https://www.datapointed.net/visualizations/math/factorization/animated-diagrams/)と[Brent YorgeyのFactorization Diagrams](https://mathlesstraveled.com/2012/10/05/factorization-diagrams/)の考え方を参考にしています。配置、Canvas描画、入力、演出はこのゲーム用に独自実装しています。参照サイトのコードや画像を実行時に読み込みません。

## 起動・検証

Python 3、開発テストにはNode.js 22以降を使います。ゲーム本体はビルド不要です。

```sh
npm ci
npm run dev
```

<http://127.0.0.1:4173/> を開きます。ES Modulesを使うためHTMLファイルの直接オープンではなくHTTPで配信してください。

```sh
npm test
npx playwright install chromium
npm run test:browser
```

ブラウザテストは一時サーバーを起動し、実際のドラッグで各ルールを攻略します。出題の再現には乱数シードと保存済み難易度を使い、ゲームモデルへ解答を注入しません。タッチでの列幅変更、数量保存、取り消し、一時停止、連続出題、保存・再開、狭い画面、クラシックの4モードを検証します。

開発サーバーの起動中に `npm run record` を実行すると、割り算・ギア・コアの操作映像を `artifacts/flow-play.webm` に記録します。接続先の変更には `CORE_BREAK_URL` を使います。操作映像と実プレイを確認し、テストが通ることだけで楽しさを判断しない方針です。

## 構成

- `src/stages.mjs`：ルール定義と解ける構成の生成。`generateProblem(ruleId, difficulty, seed, recentHistory)` は同じ入力で同じ問題を返します。
- `src/progress.mjs`：ルールごとの難易度調整と保存データの復元。
- `src/model.mjs`：永続ドットID、分割・合体、列幅、商・余り、共通幅、正方形のセル占有と発射判定。
- `src/shapes.mjs`：因数の図形、放射状のペア、余りを分離した長方形配置。
- `src/view.mjs` / `src/flow-view.mjs`：Canvas描画、ばねの動き、つまみ、配置プレビュー、連射・組み立て演出。
- `src/game.mjs`：入力、4ルールの入口、連続出題、音、保存、アクセシビリティ。`inspect()` は読み取り専用です。

同じドットは合体・分離後も同じIDを持ちます。手元、装填済み、発射済みのID集合が重ならず、常に初期の総数と一致することをテストします。Canvasの装飾には光線や破片を使い、数を表すドットを複製しません。

`main` へのpushでGitHub Pagesに配信されます。
