# CORE BREAK — Number Adventure

数ドットを合わせる・分ける・並べることで敵のシールドを突破する、ブラウザ向け算数バトルです。ビルド不要の静的サイトで、GitHub Pages に公開できます。

## 遊び方

4エリア・各9ステージ。エリアもステージも最初から自由に選べます。

| エリア | 内容 |
| --- | --- |
| スパーク | 足し算・引き算・5や10のまとまり。手持ちを押して足す、弾を押して外す。「ばらす」で1個ずつに分ける。 |
| リンク | 掛け算・割り算・偶数と奇数・余り。同じ数ずつまとめて連射する。 |
| ギア | 約数・共通の約数・最大公約数。2つのコアを同じ大きさの弾にする。 |
| コア | 素数・素因数分解・平方数。素数で分解し、PRIMEで決める。後半は素因数を同じ積の2組に分ける。 |

組み替え中は無罰、発射で判定します。スパークとリンクにはゲームオーバーがなく、ギアとコアは誤発射4回で敗北します。「組み直す」はダメージを消しません。「同じ問題で再挑戦」は最初からやり直します。

1ドット＝1を保ちます。コアの分解では、元のドットを束の中に残し、まとまりの個数と中の数量を区別します。数式は操作・発射後に表示します。

星は誤発射0回で3個、1回で2個、2回以上で1個。最高記録をこのブラウザの localStorage に保存します（アカウント・通信・端末間同期はありません）。保存できないブラウザでも遊べます。音は初期状態OFF、時間制限はありません。

既存の CASUAL / NORMAL / EXPERT / BLITZ は `classic.html` から利用できます。

## ローカル起動

Python 3 を用意して、リポジトリ直下で実行します。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:4173> を開きます。ES Modules を使うため、HTMLファイルの直接オープンではなくHTTPで配信してください。

## 開発と検証

Node.js 22以降を推奨します。ゲームの実行に npm の依存関係は不要です。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

ブラウザテストは専用の一時HTTPサーバーを起動し、36ステージを実操作でクリアします。数量の保存、記録の再読込、誤発射・再挑戦、320〜1280pxの表示、演出中の画面移動、クラシックの4モード、保存が無効な環境を検証し、終了時にサーバーを停止します。確認画像は `artifacts/` に出力します。

## 変更箇所の目安

- `src/rules.mjs`：問題データ、数の判定、状態遷移。DOMに依存しません。
- `src/areas.mjs`：エリア選択、バトル表示、入力、演出、端末内記録。`areas.css` が新エリアのスタイルです。
- `classic.html`：既存ゲームの専用入口。既存の `game.js` と拡張スクリプトを元と同じ順序で読み込みます。

新しい問題は `MISSIONS` に追加します。数量を保存し、別解を認めるか最大値などを要求するかを問題の条件に明示してください。通常の表示に学年ラベルは使いません。

`main` へのpushで既存のGitHub Pagesワークフローがサイトを配信します。
