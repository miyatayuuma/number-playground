# CORE BREAK

数そのものが、つかめる塊になる算数バトルです。手元で合体・分離させて敵へ撃ちます。ゲーム中の説明文、数字選択、正誤回答、発射ボタンはありません。

## プレイ

- 塊の中央の小さな輪、または外周をドラッグすると全体を運べます。
- 内側のまとまりやドットをつかんで引くと、その部分を取り出せます。タップだけでは分かれません。
- 手元の別の塊に重ねて放すと合体します。敵の空洞に放すと発射します。
- 分割ゲートは、ドットを長方形に整列させ、一列を残して攻撃します。商と余りは別の塊として戻ります。

4エリア・各3戦。スパークは合体と分離、リンクは等しい塊と連射、ギアは余りと共通部品、コアは分解コンボ・回転弾・スクエア攻撃を扱います。素数などの用語を知る必要はありません。初回はスパークの盤面を直接開き、左上のアイコンから全12戦を自由に選べます。

組み替えは無罰・時間制限なし。スパークとリンクは合わない弾が戻り、ギアとコアは誤発射4回で再挑戦になります。クリア記録と音の設定をこの端末のブラウザに保存します。保存が無効でも遊べます。

音の切り替えとやり直しは一時停止画面にあります。音は最初の操作で有効になります。端末の「動きを減らす」設定では移動・回転を短縮します。キーボード利用者向けの操作ボタンはフォーカス時だけ表示され、読み上げ用の説明は視覚画面とは分離しています。

既存の4モードは `classic.html` に残しています。旧36ステージ版は廃止し、進行記録を別キーにしたため、新旧のクリア記録は混ざりません。

## 数の形

1は1粒、2はペア、3は三角形、4は四角形。合成数は同じ図形が集まる再帰的な形を持ちます。4を優先して因数を取り出し、その逆順で外側から配置するため、8は四角形2つ、9は三角形3つ、12は四角形3つになります。

[Data PointedのAnimated Factorization Diagrams](https://www.datapointed.net/visualizations/math/factorization/animated-diagrams/)と[Brent YorgeyのFactorization Diagrams](https://mathlesstraveled.com/2012/10/05/factorization-diagrams/)の考え方を参考にしています。配置、Canvas描画、入力、演出はこのゲーム用に独自実装しています。参照サイトのコードや画像を実行時に読み込みません。

## 起動・検証

Python 3、開発テストにはNode.js 22以降を使います。ゲーム本体はビルド不要です。

```sh
npm ci
npm run dev
```

<http://127.0.0.1:4173/> を開きます。ES Modulesを使うためHTMLファイルの直接オープンではなくHTTPで配信してください。

```sh
npm test
npx playwright install chromium
npm run test:browser
```

ブラウザテストは専用の一時サーバーを起動し、数値を状態へ注入せずに実際のドラッグで全12戦を攻略します。タッチ入力、数量保存、部品選択、再結合、操作中断、一時停止、画面回転、記録の再読込、クラシックの4モードを検証します。スクリーンショットは `artifacts/` に出力します。

開発サーバーの起動中に `npm run record` を実行すると、合体・分離・一列残しの操作映像を `artifacts/tactile-play.webm` に記録します。接続先の変更には `CORE_BREAK_URL` を使います。操作映像と実プレイを確認し、テストが通ることだけで楽しさを判断しない方針です。

## 構成

- `src/model.mjs`：塊と永続ドットID、演算、装填、発射、商・余り、敵の判定。
- `src/shapes.mjs`：数ごとの固定形と、つかめる内部集団の座標。
- `src/view.mjs`：Canvasの描画、当たり判定、ばねの動き、連射・回転・スクエア演出。
- `src/game.mjs`：ポインター入力、画面遷移、音、記録、アクセシビリティ。テスト用の `inspect()` は読み取り専用です。
- `src/stages.mjs`：12戦の塊、標的、装填口、ゲート。問題文やヒントのフィールドはありません。

同じドットは合体・分離後も同じIDを持ちます。手元、装填済み、発射済みのID集合が重ならず、常に初期の総数と一致することをテストします。Canvasの装飾には光線や破片を使い、数を表すドットを複製しません。

`main` へのpushでGitHub Pagesに配信されます。
